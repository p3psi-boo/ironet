# 快速开始：创建并加入网络

本流程把两台 Linux 机器加入同一个 ironet 三层覆盖网络。正常部署不需要编辑 TOML，也不需要理解 endpoint ID、共享密钥或 DERP 公钥。

## 1. 前提

每台机器需要：

- Linux、`iproute2`、`iptables`、`/dev/net/tun`；
- root，或为守护进程提供 `CAP_NET_ADMIN`；
- 两台机器能够访问互联网 relay，或能够通过邀请中的固定 UDP 地址互相到达。

安装：

```bash
sudo dpkg -i ./ironet_0.1.0_amd64.deb
# 或从源码
nix develop -c cargo build --locked --release
sudo scripts/install.sh
```

## 2. 创建网络

在第一台机器执行：

```console
$ sudo ironet network create production
✓ Created network "production"
✓ Added this machine as "edge-a"
✓ Assigned overlay addresses 100.x.y.z/32, fdxx:xxxx:xxxx::x/128
✓ ironet is running

Add another machine:
  sudo ironet invite create
```

网络名用于展示；节点名默认取 hostname。高级覆盖参数包括：

```bash
sudo ironet network create production \
  --node-name edge-a \
  --address-pool 100.96.0.0/16 \
  --ipv6-address-pool fd42:6972:6f68::/64 \
  --listen 0.0.0.0:4000 \
  --no-start
```

`--no-start` 适合容器、测试和由配置管理系统启动 daemon 的环境。

新网络默认启用内嵌 MagicDNS，并生成形如
`n-<network-id>.ironet.internal` 的网络专属后缀。可以用
`--dns-domain corp.ironet.internal` 指定后缀，或用 `--no-dns` 关闭。
启动后可直接使用节点名，例如 `ping edge-a`；同名节点使用状态中显示的
`<name>-<endpoint-id前8位>` 稳定名称。

## 3. 邀请另一台机器

在第一台机器创建短期邀请：

```console
$ sudo ironet invite create --expires 1h
ironet://join/v2/...
```

邀请是签名的 bearer capability，包含加入所需的网络准入信息、为该成员预签发的节点身份和 bootstrap 定位信息。每个邀请只对应一个成员身份；重复使用不会创建第二个身份。不要把邀请提交到版本库或公开日志。

若 bootstrap 需要固定公网 UDP 地址，可在签发时加入：

```bash
sudo ironet invite create --expires 30m \
  --address 203.0.113.11:4000
```

查看与撤销本机签发的邀请：

```bash
sudo ironet invite list
sudo ironet invite revoke INVITE_ID
```

authority 节点会在会话握手时校验邀请与成员身份的绑定关系；撤销后该凭证不能再通过 authority 准入。

在第二台机器加入：

```bash
sudo ironet join 'ironet://join/v2/...'
```

自动化环境应通过文件或 stdin 传递邀请，避免进入 shell history：

```bash
sudo ironet join --invite-file /run/secrets/ironet-invite --output json
cat /run/secrets/ironet-invite | sudo ironet join --invite-file - --output json
```

## 密码直连加入（适合 NixOS 等声明式部署）

authority 节点在创建网络时读取一次密码文件。明文密码不会写入配置；配置中只保存随机
salt 与 PBKDF2 派生结果。TCP enrollment listener 与 UDP 数据面共用同一数值端口，
因此 authority 的公网入口需要同时允许 TCP 与 UDP `4000`。

```bash
# authority：/run/secrets/ironet-password 由 sops-nix、agenix 或其他 secret
# manager 提供，文件末尾的换行会被自动忽略。
sudo ironet network create production \
  --listen 203.0.113.11:4000 \
  --password-file /run/secrets/ironet-password
```

加入端不需要 invite link、network ID 或 endpoint ID，只声明 authority 与同一份
密码文件：

```bash
sudo ironet join \
  --peer 203.0.113.11:4000 \
  --password-file /run/secrets/ironet-password \
  --node-name nix-edge-a
```

加入命令先通过 TCP 接收随机 challenge，并用 password 派生密钥生成 nonce 绑定的
proof。密码不匹配时 authority 返回 `access_denied` 并立即关闭连接，不创建 invite、
不写入成员配置，也不重载数据面。验证成功后 authority 原子写入新成员、重载 daemon，
并返回一个由密码派生密钥加密的 5 分钟临时 invite；CLI 在内存中解密并继续标准
`join` 流程。加入端在本地配置与 identity 落盘后会发送确认；未确认的临时成员会在
5 分钟后自动撤销，重试会复用本地 identity，因此不会遗留不可恢复的成员。

NixOS 可以把加入命令放进一次性 systemd service，并让 `password-file` 指向声明式
secret 的运行时路径。节点已经拥有完整本地网络状态时，重复执行该命令是本地幂等
操作，不依赖 authority 在线，也不会重复签发成员。只有上一次已完成本地落盘但确认
回包丢失时，状态文件才会保留待确认阶段，下次执行仅重试该确认：

```nix
systemd.services.ironet-password-join = {
  after = [ "network-online.target" "sops-nix.service" ];
  wantedBy = [ "multi-user.target" ];
  serviceConfig.Type = "oneshot";
  script = ''
    exec /usr/bin/ironet join \
      --peer 203.0.113.11:4000 \
      --password-file ${config.sops.secrets.ironet-password.path} \
      --node-name ${config.networking.hostName}
  '';
};
```

## 4. 按需开启节点能力

发布本地 LAN 或服务网段：

```bash
sudo ironet subnet publish 192.168.50.0/24
ironet subnet list
sudo ironet subnet unpublish 192.168.50.0/24
```

发布网段默认启用返回流量 NAT。安装包会配置主机 forwarding sysctl；上线前可运行 `sudo ironet doctor` 检查。

让节点承担 overlay 中转：

```bash
sudo ironet transit enable
sudo ironet transit disable
```

这些命令会原子更新、校验并重新密封配置。daemon 已运行时自动 reload，否则输出下一条启动命令。

## 5. 查看状态和节点

直接运行 `ironet` 会展示最有用的网络摘要：

```text
Network: production
Node:    edge-a
Addresses: 100.x.y.z/32, fdxx:xxxx:xxxx::x/128
State:   ready
Peers:   1 connected
```

常用诊断：

```bash
ironet network show
ironet node list
ironet status
ironet peers
ironet ping 100.x.y.z
ironet trace 100.x.y.z
sudo ironet doctor
```

本机改名或移除一个固定节点：

```bash
sudo ironet node rename edge-primary
sudo ironet node remove edge-b --yes
```

离开网络会删除本地配置和网络状态：

```bash
sudo ironet network leave --yes
```

需要保留长期节点身份以便恢复时增加 `--keep-identity`。以后创建或加入网络时用
`--reuse-identity` 显式复用该身份。

## 6. 机器输出契约

支持机器输出的命令统一使用：

```bash
--output human   # 默认
--output json
--output jsonl
```

stdout 只承载结果；运行进度与补充提示写入 stderr。脚本应解析 JSON，不应依赖人类文本或 `sed`。

## 7. 未配置状态

未加入网络时执行 `ironet` 或 `ironet status` 会直接给出两条可执行路径：

```text
This machine has not joined an ironet network.

Create a new network:
  sudo ironet network create <name>

Join an existing network:
  sudo ironet join <invite>
```

底层配置字段、静态路由 registry 和私有链路的高级说明见 [配置参考](配置参考.md)。
